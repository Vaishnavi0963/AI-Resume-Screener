# AI-Resume-Screener

An AI-powered resume screening tool that automatically matches resumes with job descriptions using NLP and machine learning.

## Features

- Extracts text from resumes (PDF, DOCX)
- Matches resumes to job requirements
- Ranks candidates based on similarity
- Skill and keyword-based filtering
- CLI-based with clean output

## Tech Stack

- Python
- spaCy, NLTK
- scikit-learn (TF-IDF, cosine similarity)
- PyMuPDF, python-docx

## Installation

git clone https://github.com/yourusername/ai-resume-screener.git
cd ai-resume-screener
pip install -r requirements.txt

Usage

1. Place resumes in the resumes/ folder

2. Add job description in job_description.txt

3. Run the script:  python main.py

Sample Output

Top Matches:
1. Alice Johnson – 92.4%
2. Mohit Sharma – 88.1%
3. Samir Reddy – 84.6%
